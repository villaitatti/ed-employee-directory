## Design Context

### Users
ED is used by finance/admin maintainers, IT staff during v1, and later CFO/reviewer roles who need employee and department records to be accurate without hunting through spreadsheets. Users are doing focused operational work: creating records, correcting dates, importing CSV rows, exporting data, and checking audit history.

### Brand Personality
Quiet, precise, institutional. The interface should feel like a dependable internal register: dense enough for repeated admin work, calm enough for sensitive employee data, and explicit about validation and audit effects.

### Aesthetic Direction
Light theme by default for office use and spreadsheet-adjacent workflows. Avoid marketing composition, oversized hero sections, decorative gradients, and card-heavy dashboards. Use restrained color, crisp tables, clear form grouping, and compact controls that make scanning and correction fast.

### Design Principles
- Put the working surface first: tables, filters, forms, import review, and audit history are the product.
- Prefer density with breathing room over decorative emptiness.
- Make data quality visible at the row and field level before users commit changes.
- Keep Italian as the default operating language while preserving stable English API concepts.
- Treat destructive actions and overrides as explicit events with visible audit consequences.
